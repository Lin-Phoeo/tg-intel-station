## 怎么用

打开「设置 → 数据备份 → 语义检索 → 向量服务」，点绿色预设按钮即可自动填好地址与模型，
再填入该服务商的 API Key，最后点「建立向量索引」。

**建议先用本机 Ollama 试**：不用注册、不用 Key、没有额度焦虑，
13 万条向量跑完就永久有语义检索了。

## 五、为什么值得开重排

向量检索是「把查询和文档分别编码成向量再算距离」，快但粗；
重排是 cross-encoder，「把查询和文档**一起**过一遍模型」，慢但准。

所以标准做法是两段：

```
向量粗排召回 60 条  ->  重排精排  ->  返回前 30 条
```

本站在「语义检索」打勾后会多出一个「重排」开关，打开即走这条链路。
重排失败不会让整次检索失败，会**自动退回纯向量结果**并在提示里说明原因。
